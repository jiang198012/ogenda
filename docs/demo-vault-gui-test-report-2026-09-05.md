## 缺陷与改进项

### F1 — 快速新建忽略显式中文日期（确定性缺陷）

复现步骤：打开 `Ogenda: 快速新建事件`，输入：

```text
2026年9月6日15:00 GUI快速测试 1小时
```

实际结果：标题仍包含日期文字，但开始/结束日期落在系统当天 2026-09-05 15:00–16:00。

期望结果：开始/结束日期应为 2026-09-06 15:00–16:00，日期文字不应残留在标题中。
建议：补齐 `YYYY年M月D日` 的解析；解析失败时不要静默回退到“今天”，应在表单中提示日期未识别。

### F2 — 同步网络失败时增加可恢复反馈（体验改进）

切换到周视图时曾出现一次 `双向同步出错: net::ERR_CONNECTION_CLOSED`；随后手动同步成功并返回完整计数。这更像瞬态网络错误，不足以判定同步逻辑失败，但建议：

- 对瞬态连接错误做有限次数重试和退避；
- 在面板显示“上次同步时间 / 成功或失败 / 重试”状态，而不只依赖短暂 Toast；
- 视图切换触发后台同步时，避免把可恢复网络波动显示成无上下文的错误。
