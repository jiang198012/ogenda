# ogenda Agenda 面板 v3-UI 设计

**目标**:把 Agenda 面板从"能用但朴素"提升为视觉精致、信息丰富、中文友好——视觉基调重塑(参考 Agenda Tasks 的活泼信息化风格)、统一各视图、修几个遗留 bug、改善日期时间输入。

**背景**:v1(只读面板)+ v2(CRUD / 状态分组 / 统计 / 时区)已完成并过终审。用户反馈痛点:字号小且无层次、日期是英文(`Sun Jul...`)、每行信息少、几个遗留 bug。本轮 = v3-UI。

**决策来源**:brainstorming(浏览器可视化伴侣)——基调 A、清单 5 列、分类色自动派+可覆盖;terminal——日期输入用原生选择器、日期格式选 b。

**非目标**:i18n 全局中英文切换(单独立项;本轮只做**中文日期本地化**,数据层已在 v2 预留 cityZh/cityEn)。整体布局不推倒重来(保留卡片式,不改成 pill 式)。

---

## 1. 视觉体系

### 1.1 基调(方向 A · 活泼信息化)
事件卡:**左侧分类色条** + **彩色状态标签(pill)** + **强字重对比**。保留现有卡片式结构。

### 1.2 配色
- **状态色(固定 4 档)**:已确认=绿、待定=橙、已取消=灰红、未设置=灰。以 Obsidian 主题变量适配深/浅色,fallback 到固定值:
  - 已确认 `#1e9e4a` / bg `#e3f7e8`;待定 `#b26a00` / bg `#fff2dd`;已取消 `#98a0ad` / bg `#f0f0f2`;未设置 `--text-muted`。
- **分类色(动态)**:内置 10 色柔和调色板 `[#4c8dff,#ff9500,#06b6d4,#34c759,#a855f7,#ef4444,#ec4899,#eab308,#14b8a6,#6366f1]`;按分类名**稳定 hash → 索引**映射(同名同色、确定性、新分类即时有色)。设置页可为特定分类**手动指定色**覆盖自动值,覆盖表存 settings。

### 1.3 字号 / 字重
改固定 px 为 **em 相对体系**(跟随主题 `--font-text-size`),整体比现状大一档,靠字重+颜色拉开层次:
- 事件标题 ~1.05em / 700
- 时间·地点·次要信息 ~0.85em / 400 / `--text-muted`
- 状态·分类 pill ~0.72em
- 视图标题·分组头 ~0.95em / 600

---

## 2. 各视图

- **清单**:A 风格,每行 5 列——时间 | 标题(粗)+ 地点(次要行) | 状态 pill | 分类 pill + 左色条;按 status 分组、可折叠(v2 已有,套新样式)。
- **日**:卡片式(接近清单),右栏放多月迷你日历(见下)。
- **周 / 月**:格子内事件用分类色条 + 标题(小字),空白格点击新建(v2 已有)。
- **统计**:数字卡片;状态分布用状态色、分类分布用分类色。
- **多月迷你日历(#47)**:日视图右栏——当前月 + 后续月**纵向排列、按栏高动态填满**(能放几个月放几个);有事件的日子标点;点日期跳转锚点。

---

## 3. 日期中文化(#50)

中文环境显示中文日期,格式 **`2026年7月19日 星期日`**(方案 b)。涉及:导航条锚点日期、清单/卡片日期、迷你日历月标题。用 `Intl.DateTimeFormat("zh-CN", …)` 或等价实现,替换当前所有 `toDateString()`。英文环境保留英文(为未来 i18n 铺路,本轮只确保中文正确)。

---

## 4. 新建 / 编辑表单(EventFormModal)

### 4.1 原生日期时间选择器(#51)
开始/结束时间改用 `<input type="datetime-local">`;勾"全天"切 `<input type="date">`。控件值与内部 ISO 串双向转换。移除自由文本手打(彻底根治小写 t 之类的输入错误)。

### 4.2 修 3 个 bug(来自 v2 最终 review + 用户报告)
- **#52 +新建默认全天**:构造里 `allDay` 默认 `Boolean(prefillStart && !existing)`,顶部"+新建"总传非空 prefillStart 导致恒为全天。改为:全天默认值由调用方按场景显式传入——顶部新建默认**非全天**,空白格点击可保持其上下文默认。
- **#53 清空可选字段**:面板编辑走一条"可删字段"写路径(删除本次表单未填、但属可写字段集合的键),让清空生效;**不动** sync 侧 `upsertEvents` 的合并语义(那是保护 href/etag 的关键)。
- **#54 全天 end 零长度**:全天事件 `end <= start` 时即时校验/提示"填次日(排他)"。

## 5. 实现顺序(建议)

1. **配色模块**:状态色常量 + 分类色 hash 派色(纯函数)+ 设置里手动覆盖存取。
2. **视觉体系**:styles.css 重构(em 体系 + A 风格卡片/pill/色条)。
3. **各视图套用**:清单(5 列微调)、日/周/月/统计 应用新样式与配色。
4. **多月迷你日历**:扩展 mini-calendar 为多月纵向填满。
5. **日期中文化**:date-format 工具(纯函数)+ 各处替换 toDateString。
6. **表单**:原生日期时间选择器 + 修 3 bug。
7. **设置页**:分类色手动覆盖 UI。

---

## 6. 测试考虑

- **配色 hash**:纯函数——确定性、同名同色、索引边界、空/超长分类名。
- **日期格式化**:纯函数——中文格式、星期、全天 vs 带时间、跨环境 locale。
- **表单 datetime 值互转**:纯函数——ISO ↔ datetime-local/date 值、全天切换。
- **bug 回归**:+新建默认非全天、编辑清空字段往返生效、全天零长度校验。
- **视图渲染**:jsdom——新结构(色条/pill/多月迷你日历)存在且正确。

保持 v2 的 TDD 与子代理逐任务 + 终审流程。minAppVersion 维持 1.5.0(不用 1.13.0+ API);原生 `<input type="datetime-local/date">` 是标准 HTML,Electron 支持,无版本顾虑。
