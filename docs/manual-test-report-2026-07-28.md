## Issue 清单

### 1. [P0] 命令面板中不存在 Ogenda 命令

- 用例：T1.3；同时阻塞 T1.4、T9.13。
- 复现：打开命令面板并搜索 `Ogenda`。
- 实际：没有返回任何 Ogenda 命令；搜索 `settings` 能正常返回 Obsidian 命令，可排除命令面板本身失效。
- 预期：出现“打开 Agenda 面板”“立即同步日历”“获取 iCloud 日历列表”三条命令。
- 复现率：3/3。

### 2. [P1] 清单视图前后导航每次跳 7 天

- 用例：T2.2、T2.3。
- 复现：在清单视图停留于 2026-07-28，点击任一方向箭头。
- 实际：日期跳到 2026-07-21 或 2026-08-04。
- 预期：清单视图和日视图都只移动 1 天。

### 3. [P1] 关闭全天开关会丢失原时间段

- 用例：T4.5。
- 复现：以 09:00-10:00 打开表单，开启“全天”，再关闭。
- 实际：开始、结束都变成 00:00，并提示“结束时间需晚于开始时间”。
- 预期：恢复并保留 09:00-10:00。

### 4. [P1] 高密度月视图的底部内容无法可靠到达

- 用例：T6.5；在 T12.6 的 220 条事件场景再次复现。
- 复现：同一天放入 6 条以上换行事件，或加载单月 220 条事件。
- 实际：后续周行延伸到视口或状态栏下方，最后的内容无法可靠滚动到达。
- 预期：同周格子保持等高，同时所有行均可纵向访问。
- 证据：`/tmp/ogenda-test-Xzo9xk/T6-*`。

### 5. [P1] 面板宽度不超过 480px 时视图标签消失

- 用例：T6.6。
- 复现：把面板缩窄到 480px 或更窄。
- 实际：月格 70px 最小宽度和横向滚动生效，但“清单/日/周/月/统计”标签消失。
- 预期：移动端布局仍保留视图导航。

### 6. [P1] 修改存储文件夹后运行中的 FileStore 未更新

- 用例：T7.7。
- 复现：把存储文件夹改为 `Agenda-QA`，然后新建事件。
- 实际：设置已持久化到 `data.json`，事件仍写入 `Agenda/2026-07.md`，也没有创建 `Agenda-QA`。
- 预期：新事件写入新目录。

### 7. [P1] iCloud 密码错误时没有可观察到的终态错误

- 用例：T9.2。
- 复现：填写错误的 App 专用密码并获取日历列表。
- 实际：只能观察到加载提示，没有出现带 HTTP 状态码的终态失败提示。
- 预期：明确显示带 HTTP 状态码的失败提示。
- 复现率：观察到 3/3；短时 Notice 可能过快消失，仍保留取证时序风险。

### 8. [P0] 服务器拉取更新文件后，面板和编辑器仍显示旧数据

- 用例：T10.7。
- 复现：在 Apple 日历修改事件，再在 Ogenda 执行同步。
- 实际：月度 Markdown 文件已写入服务器标题，面板和编辑表单仍显示旧标题。
- 预期：文件、内存状态、面板和编辑器全部显示服务器版本。

### 9. [P0] 本地和服务器同时修改时同步无限挂起

- 用例：T10.9。
- 复现：本地与 Apple 日历分别修改同一事件，再执行同步。
- 实际：同步按钮禁用超过 2 分钟，没有完成或失败 Notice，控制台也没有错误。
- 预期：按冲突策略完成处理并报告结果，不静默丢数据。
- 证据：`/tmp/ogenda-test-Xzo9xk/T10-conflict-hung.png`。

### 10. [P1] 月度 Markdown 非法时面板空白且无错误提示

- 用例：T12.3。
- 复现：在 `Agenda/2026-07.md` 中写入非法开始日期、错误布尔值和缺少必填字段的条目，然后重启。
- 实际：事件区域空白，没有解析错误提示。
- 预期：显示可理解的错误，而不是空白面板。
